Shorts Uploader

A personal tool for publishing short videos to its owner's own YouTube channel.

What it is

Shorts Uploader is a private, single-user command line tool. It renders short vertical videos on the owner's own computer and uploads them to the owner's own YouTube channel using the YouTube Data API.

Who can use it

Only its owner. It is not distributed, has no sign-up, no website interface and no other users. It is published here solely because Google requires a home page, privacy policy and terms of service for an OAuth application.

What it accesses

One Google API scope: youtube.upload, which permits uploading videos to the authorising account's own channel. It reads nothing else and writes nothing else.
