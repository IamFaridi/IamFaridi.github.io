Privacy Policy

Shorts Uploader · last updated 15 November 2026

Summary

Shorts Uploader is a personal command line tool with one user: its owner. It collects no personal data, has no server, no database and no analytics, and transmits nothing to anyone except Google's own YouTube API.

What the application accesses

The application requests a single Google API scope, https://www.googleapis.com/auth/youtube.upload, which allows it to upload video files to the YouTube channel of the account that authorised it. It does not read your videos, comments, subscribers, watch history, email address or profile information.

What is stored, and where

After you authorise the application, Google issues an OAuth token. That token is written to a file on the owner's own computer and is used only to upload videos to the owner's own channel. It is never transmitted anywhere other than Google, and it is never shared, sold or published.

No other data is stored. The application keeps no record of who authorised it beyond the token file itself.

Third parties

There are none. Data goes only to Google, as required to perform the upload you asked for. Google's handling of that data is governed by the Google Privacy Policy.

Revoking access

You can revoke the application's access at any time at myaccount.google.com/permissions. Revoking it immediately and permanently prevents further uploads. To remove the stored token as well, delete the token file from the computer running the tool.

Limited use

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Children

The application is not directed at children and is not usable by anyone other than its owner.

Changes and contact

If this policy changes, the revised version will be posted on this page with a new date. Questions can be sent to the developer contact address registered for the application in the Google Cloud console.
